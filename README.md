# Study Hub

A platform where university students can share and access study materials.

## Features
- Multi-university support (IBU, Bilkent, Boğaziçi)
- Upload and browse notes, past exams, slides
- Comment system
- Admin panel
- JWT authentication

## Tech Stack
- **Frontend:** HTML, CSS, jQuery
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **File Storage:** Cloudinary
